# SimpWFUI

Another SimpWF UI

## Quick Start

Try SimpWFUI directly. ( Need [nodejs-24](https://nodejs.org/en/download) and [SimpWF](https://github.com/didasy/simpwf) )

```
npm install
npm run dev
```
